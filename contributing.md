# Contributing

Contributions are welcome: a tool, a research link, a word list, or a language section.

Please keep entries useful and reviewable:

- Add only real, working resources.
- Prefer resources that can be used locally, inspected, or independently verified.
- Keep descriptions to one plain sentence.
- Put resources in the most specific section they fit.
- For language sections, native-speaker review is strongly preferred.
- Treat AI-text detectors cautiously. Do not suggest detector scores for high-stakes decisions about a person.
- Do not add thin "humanizer" tools whose only claim is detector evasion.
